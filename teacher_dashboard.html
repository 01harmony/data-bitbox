교사 대시보드 연결

(교사 대시보드를 사용할 경우)

본인이 배포한 웹 앱 주소와 관리자 비밀값(ADMIN_SECRET)을 입력하세요. 이 브라우저에만 저장되며, 어떤 파일에도 기록되지 않습니다.

📖 처음 사용하시나요?
  1. 템플릿 시트 사본 만들기 링크를 열고 [사본 만들기]를 클릭합니다. 구글 시트와 Apps Script 코드(Code.gs)가 한 번에 내 드라이브로 복사됩니다.
  2. 복사된 시트에서 [확장 프로그램] → [Apps Script]를 열고, 코드 맨 위쪽의 SECRET_KEY와 ADMIN_SECRET 값을 각각 본인만의 값으로 바꾼 뒤 저장합니다.
  3. Apps Script 화면 오른쪽 위 [배포] → [새 배포]를 클릭하고, 유형에서 웹 앱을 선택합니다.
  4. "액세스 권한"을 반드시 모든 사용자로 설정한 뒤 [배포]를 클릭합니다. 권한 승인 창이 뜨면 허용해주세요.
  5. 배포가 끝나면 나오는 웹 앱 URL을 복사해서, 아래 "Apps Script 웹 앱 URL" 칸에 붙여넣습니다.
  6. 방금 Code.gs에 입력한 ADMIN_SECRET 값을 그대로, 아래 "관리자 비밀값" 칸에 입력합니다.
  7. [연결하기]를 누르면 완료!
    이 정보는 지금 사용 중인 브라우저에만 저장되므로, 다른 컴퓨터·다른 브라우저에서 열 땐 같은 방법으로 한 번 더 입력해주세요.
🔑 관리자 비밀값을 잊어버렸어요
1. 데이터가 쌓이는 구글 시트를 엽니다.
2. [확장 프로그램] → [Apps Script]를 클릭합니다.
3. 왼쪽 파일 목록에서 Code.gs를 열고, 맨 위쪽에서 const ADMIN_SECRET = "..." 줄을 찾습니다.
4. 큰따옴표 " " 안의 값이 관리자 비밀값입니다. 그대로 복사해서 위 칸에 입력하세요.

값을 아예 새로 바꾸고 싶다면, 이 줄의 값을 원하는 문자열로 수정한 뒤 [배포] → [배포 관리] → 연필 아이콘 → 버전: 새 버전으로 다시 배포해야 적용됩니다.
⚠️ 학생 제출용 SECRET_KEY가 아닙니다. Code.gs 상단의 ADMIN_SECRET 값을 입력하세요.
